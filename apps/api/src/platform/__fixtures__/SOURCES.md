# Fixture sources

- `public-jsonresume-sample.json` / `public-cv-richard-hendriks.txt`: official JSON Resume schema sample (`jsonresume/resume-schema` sample.resume.json), converted to plain text for extract tests.
- `public-cv-byungjin-park.txt`: plain-text rendering of the public Awesome-CV example resume (CC BY-SA 4.0, https://github.com/posquit0/Awesome-CV examples), contact fields from examples/resume.tex.
- `public-cv-vietnam-backend.txt`: Vietnamese-diacritic backend CV fixture for enrichment/export (synthetic public-style sample for diacritics + enrich assertions).
- `backend-engineer-en.txt` / `backend-engineer-vi.txt`: signal-rich lab fixtures used by unit tests.
