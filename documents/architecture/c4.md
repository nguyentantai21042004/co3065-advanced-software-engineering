# C4 — AI Coach

## Context

```mermaid
C4Context
  title AI Coach — System Context
  Person(user, "Candidate / student", "Uploads a CV and reads structured analysis")
  System(aicoach, "AI Coach", "Auth, CV storage, extract, analysis")
  System_Ext(gemini, "Google Gemini", "Optional LLM. Stub used when GEMINI_API_KEYS is empty")
  System_Ext(object, "Object storage", "Local filesystem by default; optional S3/R2")
  System_Ext(pg, "Postgres", "PGlite in-process by default; optional Neon/Postgres via DATABASE_URL")
  Rel(user, aicoach, "HTTPS (browser)")
  Rel(aicoach, pg, "SQL")
  Rel(aicoach, object, "Put/Get CV bytes")
  Rel(aicoach, gemini, "HTTPS generateContent (optional)")
```

Users talk only to AI Coach. The demo process owns the database, file bytes, and the extract/analyze pipeline. Gemini is a replaceable analysis backend, not a required runtime.

## Container

```mermaid
C4Container
  title AI Coach — Containers
  Person(user, "User")
  Container(web, "Web", "Next.js App Router :3000", "Landing, auth, dashboard upload/processing/results/history/profile/settings")
  Container(api, "API", "Hono / Node :8090", "JWT auth, CV HTTP, in-process extract worker")
  ContainerDb(db, "Postgres", "PGlite or DATABASE_URL", "users, uploaded_file, extraction_result, cv_analysis_result")
  Container(files, "File store", "fs or S3/R2", "Raw CV bytes keyed by file_id")
  Container_Ext(gemini, "Gemini", "Optional")
  Rel(user, web, "HTTP :3000")
  Rel(web, api, "JSON /api/* :8090, snake_case envelope")
  Rel(api, db, "SQL")
  Rel(api, files, "put/get")
  Rel(api, gemini, "optional analyze")
```

One Node API process does both HTTP and async extract (no separate consumer, no RabbitMQ). The Next app is a BFF-less SPA/RSC shell that calls the public HTTP contracts directly.
