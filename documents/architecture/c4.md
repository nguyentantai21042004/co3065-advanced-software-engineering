# C4 — AI Coach

Mermaid diagrams below use **flowchart** syntax (GitHub-safe). They map to C4 **Context** and **Container** levels. Avoid `C4Context` / `C4Container` blocks here — GitHub’s Mermaid bundle does not ship the C4 plugin reliably.

## Context (C4 L1)

```mermaid
flowchart TB
  user(["Candidate / student"])
  aicoach["AI Coach<br/>auth, CV store, extract, coaching report, PDF/Word export"]
  gemini["Google Gemini<br/>optional LLM"]
  object["Object storage<br/>local FS or S3/R2"]
  pg[("Postgres<br/>PGlite or DATABASE_URL")]

  user -->|"HTTPS browser"| aicoach
  aicoach -->|"SQL"| pg
  aicoach -->|"put / get CV bytes"| object
  aicoach -->|"generateContent optional"| gemini
```

Users talk only to AI Coach. The demo process owns the database, file bytes, and the extract/analyze pipeline. Gemini is a replaceable analysis backend, not a required runtime.

## Container (C4 L2)

```mermaid
flowchart TB
  user(["User"])

  subgraph monorepo["AI Coach monorepo"]
    web["apps/web<br/>Next.js :3000<br/>auth + dashboard"]
    api["apps/api<br/>Hono :8090<br/>JWT + CV HTTP + coaching report + PDF/Word export"]
    shared["apps/api/src/contracts<br/>Zod snake_case contracts"]
  end

  db[("Postgres<br/>PGlite or DATABASE_URL")]
  files["File store<br/>.data/files or S3/R2"]
  gemini["Gemini<br/>optional"]

  user -->|"HTTP :3000"| web
  web -->|"JSON /api/* :8090"| api
  web -.->|"imports types"| shared
  api -.->|"imports contracts"| shared
  api -->|"SQL"| db
  api -->|"put / get"| files
  api -->|"analyze optional"| gemini
```

One Node API process does both HTTP and async extract (no separate consumer, no RabbitMQ). The Next app calls the public HTTP contracts directly.

Monorepo mapping:

| Container | Path |
| --- | --- |
| Web | `apps/web` (`@aicoach/web`) |
| API | `apps/api` (`@aicoach/api`) |
| Wire contracts | `apps/api/src/contracts` + `apps/web/src/types/wire` |

## Code (inside the API container)

See [logical.md](logical.md). Request path: `routes → handlers → service → repo`, with platform adapters for DB, storage, queue, JWT, and LLM. Modules live under `apps/api/src/modules/{users,cv,system}`.
